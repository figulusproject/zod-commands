> _Everyone has the right to resist occupation._

Zod schema-driven parsing for how a program takes input from a person, in whatever form that takes: CLI flags, interactive prompts, or the introspection logic shared by both.

See the [docs site](https://zodintake.figulus.dev/) for everything below.

## Packages

- [zod-commands](/packages/zod-commands/) | CLI flags, positionals, and subcommands

Each is independently published and independently versioned - see its own README for installation and usage.
